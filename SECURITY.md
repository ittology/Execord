# Security Policy

**Last updated:** August 21, 2026

## Reporting a Vulnerability
If you discover a security issue in Execord (such as permission escalation or unintended command execution), please report it privately:
- **Email:** [ittology.contact@gmail.com](mailto:ittology.contact@gmail.com)
- **Support Discord:** [https://discord.gg/BBJTAsd8jy](https://discord.gg/BBJTAsd8jy)

Please provide details, reproduction steps, and your Discord User ID if you wish to be credited.
